# ArenaModelCompanion 美元额度卡片补丁

版本：1.0.0 · 2026-09-22

## 这是什么

把 `Arena Trace Inspector 2.3.0` 中美元额度卡片的显示逻辑适配到你当前的 ArenaModelCompanion：在聊天窗口右侧「模型监测」面板顶部新增圆环额度卡片，显示美元剩余额度、总额度、剩余百分比、累计已用、额度档位、窗口起始和记录读取时间。

这是**现有安装的单文件补丁包**，不是完整软件安装器，不需要安装 C 盘浏览器插件，也不替换 EXE。它不修改实例中心管理器的卡片列表。

本包适配制作时读取的 `D:\新建文件夹\ArenaModelCompanion\assets\arena-model-probe.inject.js`。安装器会核对原文件 SHA-256；版本不符时拒绝覆盖。

## 安装方法（推荐）

1. 下载 ZIP，解压到一个独立目录，例如桌面。**不要直接解压覆盖原软件目录。**
2. 完全退出 Arena 筛选助手、所有实例及实例管理器。无需删除任何账号或数据。
3. 打开解压后的 `ArenaModelCompanion-USD-Patch` 文件夹，双击 **`Install.cmd`**。
4. 默认安装目录为 `D:\新建文件夹\ArenaModelCompanion`。核对屏幕上的路径，输入大写 **`YES`** 确认。
5. 出现安装完成后，用你原来的快捷方式或 EXE 启动软件。
6. 打开 Agent 会话，在右侧「模型监测」面板顶部查看「美元账户额度」。如果面板已收起，先展开。

安装脚本仅在你手动运行并确认后执行。它会：校验版本 → 检查目标目录内运行中的程序 → 备份 → 暂存校验 → 替换一个 JS 文件 → 核验结果。不会强制结束进程。

原文件自动备份在：

```text
D:\新建文件夹\ArenaModelCompanion\USD-Quota-Backups\日期时间-随机标识\arena-model-probe.inject.js
```

若软件路径不同，打开 PowerShell，执行（替换补丁包和软件目录）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\补丁包位置\ArenaModelCompanion-USD-Patch\Install.ps1" -TargetRoot "D:\你的软件目录"
```

`ExecutionPolicy Bypass` 仅用于这一次 PowerShell 进程，不更改系统长期执行策略。受组织策略限制时，不要绕过组织安全规则，请联系管理员或使用下述手动复制方式。

## 完全手动复制（不运行脚本）

1. 退出全部相关程序，并先把原软件整个 `assets` 文件夹备份到其他位置。
2. 核对原文件哈希与 `manifest.json` 中 `originalSha256` 一致：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath "D:\新建文件夹\ArenaModelCompanion\assets\arena-model-probe.inject.js"
```

3. 只复制补丁包中 `assets\arena-model-probe.inject.js`，覆盖软件安装目录下同名文件。
4. 再计算哈希，确认与 `manifest.json` 中 `patchedSha256` 一致。
5. 重新启动软件。

**只替换上述一个文件。不要复制覆盖 Data、Browser、EXE 或 manager-src。哈希不一致时不要强行覆盖。**

## 什么时候能看到金额

- 数据来自已有探针采集的本会话 `spend.recorded` 服务端记账记录，不调用旧的 `/api/billing/balance`。
- 它是**最近已采集运行的账户额度快照**，不是实时余额接口，不是可提现现金或充值金额。多个窗口或其他设备的后续消耗可能尚未反映。
- 新安装后已有旧页面可能没有新数据。正常使用并完成一轮回答后，随原探针采集刷新。补丁自身不会自动发送测试消息、生成内容或抽卡。
- 新一轮、不同页面、不同运行或生成标识不匹配时，不借用旧记录；显示“未提供”不是余额为零。
- 无字段、记录未完成、采集被截断、探针没有读到记录，或网站以后改变字段时，金额可能一直显示“未提供”。不会从 credits、pulse 或 token 猜算美元。
- 卡片每秒重绘检查的是内存中的记录，**不是每秒发送网络请求**。快照超过 5 分钟会提示可能过期。
- 金额默认保留两位小数，鼠标悬停金额可查看至多八位小数，微小消耗可能不改变两位小数的显示。
- 切换账号建议完全退出当前实例后重开。本补丁沿用原探针的页面、Run 和生成标识隔离，不另行读取登录凭据来验证账号归属。

## 回退

1. 完全退出相关程序。
2. 双击补丁包的 **`Restore.cmd`**，核对目标路径，输入大写 **`YES`**。
3. 重新启动软件。此操作只恢复制作补丁时的原始 JS 文件。

如果此后又更新过软件，回退脚本会因哈希不匹配拒绝覆盖。不要强制使用旧文件覆盖新版，应恢复与你当前版本匹配的备份。

也可在退出程序后，把你安装前备份的 `arena-model-probe.inject.js` 复制回软件的 `assets` 文件夹。

## 排障

- **提示版本不一致**：当前文件被软件更新或其他修改改变。保持原状，提供当前版本重新适配。
- **提示仍有程序运行**：自行退出对应实例及管理器，不要在运行中替换文件。
- **没有新卡片**：确认替换的是实际启动的 EXE 所在目录的 `assets`；完全退出后重开，不只是刷新管理器。
- **卡片出现但金额未提供**：查看卡片提示和原面板的采集诊断；先确认原探针能取得当前运行的完整记录。不要为排障反复发送付费请求。
- **运行错误或界面异常**：退出并按回退步骤恢复，保留错误提示供排查。
