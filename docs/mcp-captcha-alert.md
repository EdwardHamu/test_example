# 人机验证警告音

- 在 assets/arena-model-probe.inject.js 新增 captcha-alert 模块，并在 boot 中启动。
- 每 750ms 检查可见 dialog/alertdialog 中的 Security Verification、人机身份验证等文案，以及已知服务的可见挑战 iframe。排除隐藏元素、聊天日志内元素和小尺寸验证码框，不读取跨域 iframe 内容。
- 采用独立三声高低交替提示（约 1.25 秒，峰值增益 0.22），与完成提示音区分。
- 同一次持续显示仅提示一次；连续两次检查未检测到后重置，随后重新出现可再次提醒。初始化时已经显示的弹窗也能提示。
- 遵循现有通知开关；关闭通知时不播放警告。重新启动监听会停止旧定时器。
- 仅提示手动处理，不点击、关闭、破解或绕过验证。不改变完成通知、自动 Esc 或抽卡 10 秒冷却。
- 仅能检测当前注入网页 DOM；不覆盖操作系统/桌面原生弹窗、所有未知验证码样式或新窗口。后台页面定时器可能被节流，声音受自动播放与静音设置影响。未进行真实网页人机弹窗联测。
- 新增 tests/captcha-alert.test.cjs：9 项模块加载、可见性、来源域名、去重、开关、定时器清理及音频测试。全部 72 项回归测试通过，JS 语法与 git diff --check 通过。
- 刷新页面或重启应用加载新代码；未修改 EXE，未提交或推送 Git。
