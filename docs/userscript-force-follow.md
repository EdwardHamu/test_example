# 独立强制置底开关

> 2026.09.25.27：按最新要求，实际跟随条件改为“开关开启 AND 检测到生成中”。生成完成后不再置底，开关仍保持开启以等待下一轮。继续不判断用户上滚、不与账号校验联动、保留开关偏好。下文 2026.09.25.26 的完成后继续置底行为已被替代。

版本 2026.09.25.26。

入口：Arena 工具 → 会话与导出 → “强制保持聊天区底部（开启后上滚也会拉回）”。复用原跟随复选框，不保留两个冲突开关。

开关打开即持续固定当前聊天消息区底部，生成中或完成后均维持，不再依赖停止按钮或 React 生成状态来决定是否滚动。用户上滚、布局收缩不会暂停；关闭后立即停止，包括已排队的帧回调。要阅读历史请先关闭。

移除账号模块对 setEnabled(false) 的调用，账号校验失败、超时及账号切换不改变这个纯浏览开关。抽卡/发送等账号安全保护不变。

首次没有偏好默认关闭。localStorage 键 arena-force-follow-bottom 保存布尔字符串；刷新后沿用。存储不可用时仍可在当前页使用。该偏好是页面站点级而非按账号保存。

继续使用 MutationObserver、ResizeObserver、scroll 事件合并到 requestAnimationFrame，350ms 轮询兜底。真实消息滚动容器仍按 transcript 标记和 overflow 测量定位。不会为此修改 composer 样式。浏览器节流、网页卸载或隐藏消息区时不能承诺零延迟强制显示。

修改共享 assets/FollowLatest.js、tools/userscript-account-compat.js 和 tools/userscript-adapter.js。已有 userPaused 字段保留兼容但恒为 false。显式 suspend 仍用于硬停用；账号模块不调用它。

旧暂停上滚/自动生成测试按新交互规则替换，并增加持久化、立即关闭、账号失败不联动等测试。Node 替身测试不代表已完成真实浏览器验收。
