# 账号密码默认保存（2.0.3）

按用户要求，迁移确认明确包含旧库已有密码，取消整体迁移不上传；不再另行询问是否上传密码。登录表单默认勾选加密保存密码，登录方法未指定 remember 时也默认保存，显式 false 仍不保存并删除已有密码。自动重登录 preservePassword 行为不变。

密码使用既有服务端加密密码接口，客户端不新增密码持久化。迁移读回校验密码后才允许清理旧库，失败保留本地旧库；同邮箱远程账号仍跳过、不覆盖。因此先前已迁移但未保存密码的账号，需通过密码管理补录或再次使用邮箱密码登录；重跑迁移不会补写重复账号。Cookie 无法还原原始密码。
