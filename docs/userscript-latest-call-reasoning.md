# 多调用场景使用最新一次调用的思考等级（2026.09.26.4）

## 行为

可以从最新调用判断显式思考等级，不应仅因同轮多次调用而一律显示未知。本版本保留逐调用明细，并让探针主标题/档位区显示最新调用自己的模型名和显式配置，附“最新调用”及 Span 来源，不把它解释为整轮统一档位。

- 只在当前会话、run、generation 已校验的最新轮次内选择。
- 如果全部调用具有 Trigger.dev `startTime` 纳秒字符串，使用 BigInt 比较开始时间，保留纳秒精度；最新时间相同则无法唯一判断，仍显示未知。
- 时间戳不完整时，使用采集器保存的 Trace 事件序号，明确标为“按 Trace 顺序”。这是最新记录位置，不额外声称已证实实际执行的先后或结束先后。
- 旧详情若没有时间/序号，或序号重复、读取被截断/停止，不猜测最新调用。
- 最新调用尚未完成或没有显式参数时显示未知，绝不退回旧调用的 high。
- 多调用时仅使用选中 Span 的配置，不合并页面请求或其他调用的配置。冲突和不支持值维持原规则。
- 预算、模式仍独立；不由后缀、耗时或 Token 数推测等级。
- 原轮次级用量/费用/内部型号关联仍保持保守处理，不因显示最新档位而把多个记录错误归给一个调用。

## 源码

`assets/arena-model-probe.inject.js`：保留安全的 startTimeNs / traceOrder，trace-summary 增加 latestCall，desktopFacts 与 HUD 使用该调用自己的模型名/档位。

`tools/userscript-reasoning.js`：通过既有 automaticTrace.summary 标记最新调用卡片；不安装新拦截器或增加请求。

模块清单仍为 16 项。按架构指南静态构建，版本统一更新到 2026.09.26.4；安装文件由构建工具生成，不手改。
