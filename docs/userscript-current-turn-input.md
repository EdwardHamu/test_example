# 折叠用量浮窗：当前轮次输入 Token

版本：2026.09.25.20。

修改 tools/userscript-session-usage.js，根目录 user.js 由构建工具生成。

折叠标题改为“本轮输入”，单位 k（1k = 1000 Token），最多三位小数并移除末尾零：0 → 0k，1 → 0.001k，1200 → 1.2k，12345 → 12.345k。鼠标提示保留完整 Token 数。

数据口径：仅当前账号、当前会话对应的当前 run。优先使用通过 URL/runId/generation 校验的当前 trace 中最大 turn 的输入量；同一 turn 内沿用原有去重及完整记录统计规则。不累加此前 turn 或其他 run。没有可用 trace turn 时使用当前 run 的最新 usage.input 参考；若已知最新 turn 但其输入缺失，则显示 —，不回退至较早调用。

不完整的已知数保留 *。新 run 尚无数据、未确认账号、跨会话或刷新后只有历史账本时显示 —，不虚构零。当前轮次指探针当前 run 已观测到的最新 turn，不能推断尚未采集的未来调用。

展开面板继续显示会话累计统计，存储、费用计算与数据采集方式不变；不新增网络请求。

新增多轮非累加、新 run 清空、缺失最新轮、k 格式及重载历史隔离测试。全量 398 项自动测试通过；日志 userscript-build/current-turn-usage-tests.tap。尚未真实浏览器验收。
