## 2. 同步名称规则

“探针名称”指 `window.__MODEL_PROBE__.conversationModels()[当前会话 UUID]` 的已匹配名称，不是检查器 API 展示名，也不是页面标题或侧栏 DOM 文本。

| 内部名 | 探针名 | 同步值 |
|---|---|---|
| 未提供 | `fable` | `fable` |
| `fable` | `fable` | `fable` |
| `fable-high` | `fable` | `fable-high` |
| `fable` | `fable-preview` | `fable` |
| `CLAUDE_OPUS_4.6_HIGH` | `Claude Opus 4.6` | `CLAUDE_OPUS_4.6_HIGH` |
| `internal-route` | `astra` | `internal-route-astra` |
| `internal-route` | 未提供 | `internal-route` |
| 都未提供 | — | 不写入 |

“部分一致”的实现边界：去首尾空白，比较时进行 Unicode NFKC、忽略大小写，将空白、横线、下划线、点、冒号及斜线规范为分隔符，再检查一方的**完整规范化名称**是否被另一方包含。包含必须位于词段边界；不是“只要有任何共同字符或词就算相同”，也不猜型号别名/家族。`model-a` / `model-b`、`model-1` / `model-10`、`gpt-4` / `gpt-4o` 仍按不同名称处理。只规范化比较，不改写最终内部名的原始拼写。

### 来源与安全保护

- 检查器 `modelIdentity()` 只提供当前账号、会话、run、generation、轮次与完成状态都通过校验的内部名；当前最新调用与详细 Span 必须相符。不会把多调用中的轮次级内部名随意分配给某一调用。
- 缺少内部名、检查器暂未就绪、内部记录不完整或冲突时，不选旧内部名，也不用检查器展示名猜测；已有探针名可独立同步。
- 未确认账号不写入。写入绑定已确认账号作用域，作用域更换或失效即停止；既有账号事件、epoch、重载与中止保护保留。
- 只从当前会话条目建立新同步观察。其它会话的缓存名、其它会话或错误来源的内部名不能污染当前名称。
- 不读取 Cookie 或认证信息；Bearer/JWT 形态、控制字符、未知占位和非字符串不进入模型字段。组合超过接口的 200 字符限制时不截断，也不写入。
- 思考等级只用于 UI，不进入同步字符串。真实内部型号本身的 `-high` 等后缀保持原样；仅等级变化不会改写会话模型。
- 保留固定跨域助手、请求去重/重试、响应匹配、服务器确认后再改侧栏文本、当前会话查询与多侧栏回填；不修改 Arena 保存的聊天标题。
