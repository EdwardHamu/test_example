# 抽卡命中自动修改会话名

已更新 user.js，版本 2026.09.24.2。抽卡状态机确认当前会话命中主要或次要目标时，通过 CandidateBridge 执行侧栏菜单 → Rename → 填入名称 → 保存 → 核验标题。

## 命名规则

格式为「实际模型名 空格 序号」，例如 `gemini-2.5-pro 1`、`gemini-2.5-pro 2`。每种模型独立编号，从 1 开始；大小写和首尾空格归一化后计数。实际模型名不是目标关键词。名称最多 100 个 JS 字符单元，超长模型名截短，序号保留。

序号和会话记录存储在 arena.ai 当前浏览器配置的 localStorage，键为 `arena-userscript-hit-names-v1`。刷新后保留，不会跨设备/浏览器同步，也不隔离同一浏览器中切换的账号。失败时已预留的序号不会回收，允许跳号，避免重试造成混用。支持 Web Locks 时跨标签串行预留；不支持时建议仅开一个抽卡标签，不能承诺跨标签绝对无重复。

## 触发和保护

- 不依赖外部广播；即使广播关闭也可命名。
- 覆盖 answer 正常识别、主目标检查及 resume 恢复路径；普通非目标模型不触发。
- 检查当前 URL、模型所属 URL 与相应生成轮次。执行过程每次 UI 动作前重新检查 URL，切换会话后不在新会话保存。
- 同会话同模型的重复轮询只处理一次；已成功记录在刷新后不再递增。失败本页不反复点击，刷新后可重用预留编号再试。
- 命名过程中暂缓抽卡状态机，避免自己的 Rename 对话框被当成外来阻塞或次要目标尚未保存就开新会话。结束后主要目标仍停止，次要目标仍按原 40 秒冷却规则继续。
- 已存在的用户重命名菜单/窗口不被接管；找不到唯一菜单、保存超时、存储不可用等情况记录失败，不继续强行点击。失败后遗留的窗口由用户处理。
- 工具面板“自动命名状态”显示结果；失败会打印控制台警告。未增加自动重试按钮。
